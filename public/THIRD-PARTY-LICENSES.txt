BGPShark - third-party licenses
===============================

BGPShark makes no third-party requests. Nothing is pulled from a CDN at
runtime: the typefaces and the libraries are copied into the build and served
from the app's own origin, which means the app redistributes them rather than
merely linking to them. Redistribution is what carries an obligation - the SIL
Open Font License and the MIT License both require the copyright notice and the
license text to travel with the copy.

This file is that copy. It lives in public/, so it is a plain file in the
repository and is also served with the built site at
/bgpshark/THIRD-PARTY-LICENSES.txt.

Adding a bundled font or a runtime dependency means adding it here.


FONTS
=====

Four WOFF2 files ship with the app: two weights of each family, subset to Latin
because everything this instrument displays is IP addresses, ASNs and protocol
field names. The files are therefore conversions and subsets of the originals
rather than the originals themselves. Both families are licensed under the SIL
Open Font License, Version 1.1, reproduced in full below.

IBM Plex Sans - interface text, weights 400 and 600.
https://github.com/IBM/plex

    Copyright © 2017 IBM Corp. with Reserved Font Name "Plex"

JetBrains Mono - addresses, prefixes, hex dumps and anything else that has to
line up in a column. Weights 400 and 500.
https://github.com/JetBrains/JetBrainsMono

    Copyright 2020 The JetBrains Mono Project Authors
    (https://github.com/JetBrains/JetBrainsMono)

LIBRARIES
=========

The runtime dependencies are compiled into the JavaScript and WebAssembly the
browser downloads, so they are redistributed the same way the fonts are. All
three are under the MIT License, whose text follows the notices.

React and React DOM - the user interface. Includes "scheduler", which React
depends on and which carries the same notice.
https://github.com/facebook/react

    Copyright (c) Facebook, Inc. and its affiliates.

React Router - routing between screens.
https://github.com/remix-run/react-router

    Copyright (c) React Training LLC 2015-2019
    Copyright (c) Remix Software Inc. 2020-2021
    Copyright (c) Shopify Inc. 2022-2023

DuckDB-Wasm - the database behind the SQL console. Its .wasm module and its
worker are served from this origin rather than from a CDN, which is what lets
the SQL console work offline.
https://github.com/duckdb/duckdb-wasm

    Copyright 2018-2025 Stichting DuckDB Foundation
